# 🏠 RoomMate Finder

> **RoomMate Finder** — веб-сервис для поиска и подбора сожителей среди студентов для совместной аренды жилья с использованием системы рейтинга пользователей.

Проект предназначен для решения проблемы поиска надежных соседей для совместного съема квартиры или комнаты в студенческой среде (для студентов, которым ВУЗ не предоставил место в общежитии, а съём квартиры для одного выходит слишком дорого). Главная особенность сервиса — система рейтинга и отзывов, которая помогает сформировать уровень доверия между студентами еще до заключения договора аренды.
