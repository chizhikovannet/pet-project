Атрибуты качества, прочие требования и приложения

6.1 Удобство использования 

Понятность API: Документация API должна автоматически генерироваться через Swagger UI (/docs) и ReDoc (/redoc) с наглядными примерами JSON-запросов и ответов.

Информативность ошибок: При возникновении ошибок валидации или авторизации API должен возвращать понятные сообщения с указанием причины (например, Пароль слишком короткий или Пользователь с таким логином уже существует).

6.2 Производительность

Время отклика: Время обработки простых REST API запросов (получение профиля, отправка сообщения) не должно превышать 200 мс при нормальной нагрузке.

Масштабируемость: Использование асинхронного фреймворка FastAPI позволяет обрабатывать параллельные HTTP-запросы без блокировки основного потока.

Оптимизация БД: Использование индексов для внешних ключей (user_id, chat_id) и полей поиска (city, university, budget).

6.3 Безопасность 

Хранение паролей: Все пароли пользователей хранятся исключительно в виде хэшей с использованием алгоритма bcrypt. Хранение паролей в открытом виде строго запрещено.

Передача данных: Все коммуникации между клиентом и сервером должны осуществляться по защищенному протоколу HTTPS (TLS 1.2+).

Авторизация: Доступ к защищенным ресурсам (чаты, создание отзывов, редактирование анкеты) осуществляется строго по валидному JWT-токену.

Защита от накруток: Система рейтинга проверяет уникальность пары «автор отзыва — получатель» для исключения дублирования оценок.
