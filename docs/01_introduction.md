Спецификация требований к программному обеспечению (SRS)

Проект: Веб-сервис для поиска и подбора сожителей среди студентов с использованием системы рейтинга пользователей («RoomMate Finder»)

Введение

1.1 Назначение
Настоящий документ определяет функциональные и нефункциональные требования к веб-сервису «RoomMate Finder», предназначенному для поиска и подбора сожителей среди студентов для совместной аренды жилья. Документ содержит подробное описание целей проекта, пользовательских ролей, системных функций, требований к данным и внешним интерфейсам.

Основное отличие и практическая ценность сервиса заключаются в интеграции системы рейтинга пользователей и взаимной оценки, направленной на повышение уровня доверия, безопасности и прозрачности при поиске сожителей в студенческой среде.

Документ предназначен для разработчиков, тестировщиков, а также для защиты квалификационной работы.

1.2 Соглашения, принятые в документах
При составлении данного документа приняты следующие соглашения и обозначения:

Терминология и сокращения:

API (Application Programming Interface) — программный интерфейс приложения.

JWT (JSON Web Token) — стандарт токенов для аутентификации пользователей.

Сожитель / Руммейт (Roommate) — кандидат для совместного найма жилого помещения.

1.3 Границы проекта
В границы проекта входит:

Разработка REST API backend-сервиса на базе фреймворка FastAPI.

Модуль аутентификации и авторизации пользователей с подтверждением студенческого статуса.

Модуль создания, редактирования и архивации анкет пользователей (с базовыми параметрами: ВУЗ, бюджет, привычки, наличие питомцев, район).

Модуль поиска и многокритериальной фильтрации анкет.

Модуль интерактивной системы рейтинга и отзывов (оценка надежности, чистоплотности, коммуникабельности и т.д.).

Модуль избранного и управление списком сохраненных анкет.

Модуль обмена личными сообщениями (чаты) между пользователями.

В границы проекта НЕ входит (вне текущей реализации):

Публикация объявлений о сдачи квартир в аренду.

Встроенный модуль онлайн-оплаты аренды или залога через банковские эквайринги.

Автоматическая юридическая проверка договоров найма жилья.

Физический осмотр жилых объектов администрацией сервиса.
